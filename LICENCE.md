## 🧩 About

**Krunker Overlay Menu** is a curated list of Krunker open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD viewer, session panel
- **Quality-of-Life Helpers** — crosshair catalog, loadout notes, keybind manager
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Session Panel — track private-map runs and scores
- Map Viewer — browse layouts for offline study
- Replay Notes — record and review movement routes
- Playback Speed — adjust editor playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Crosshair Catalog — browse reticles, colors, and outlines
- Custom Loadout Notes — organize player loadout presets
- HUD Visibility — improved on-screen information layout

### 🏋️ Practice Layout
- Warmup Notes — segment study on any private map
- Movement Control — manually adjust speed settings in the editor
- Jump Buffer Notes — chain complex maneuvers in the editor
